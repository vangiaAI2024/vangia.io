# Course Summary: 12 Learning Flashcards

---

### Card 1: Supervised Learning Foundations
*   **Topic**: Machine Learning Basics
*   **Core Concepts**: Supervised vs. Unsupervised vs. Reinforcement Learning paradigms.
*   **Algorithms**: Hands-on implementation of SVM, KNN, Logistic Regression, Decision Trees, and Naive Bayes classifiers.

---

### Card 2: Unsupervised Clustering & Text Vectorization
*   **Topic**: Data Discovery & Representation
*   **Core Concepts**: Finding patterns in unlabeled data and converting text to numerical formats.
*   **Key Tools**: Hierarchical Clustering, TF-IDF text features, and advanced Data Visualization techniques.

---

### Card 3: Neural Network Architectures & Validation
*   **Topic**: Deep Learning Core
*   **Core Concepts**: Forward propagation, loss computation, and backpropagation optimization.
*   **Network Types**: Feedforward Networks (FFN), Convolutional Networks (CNN), Recurrent Networks (RNN), and evaluation metrics.

---

### Card 4: Transformers & Ensembling Techniques
*   **Topic**: Modern Sequence Models
*   **Core Concepts**: The "Attention Is All You Need" architecture, self-attention mechanics, and latent spaces.
*   **Optimization**: Exploring the Variance of Embeddings and combining models via Ensembling for robustness.

---

### Card 5: LLM Pre-training & Fine-Tuning
*   **Topic**: Generative AI Customization
*   **Core Concepts**: Downstream adaptation strategies for large foundation models.
*   **Efficiency**: Implementing Parameter-Efficient Fine-Tuning (PEFT) using memory-optimized LoRA and QLoRA layers.

---

### Card 6: Reinforcement Learning & HITL Alignment
*   **Topic**: Reward-Based Optimization
*   **Core Concepts**: Training models through trial, error, and feedback loops.
*   **Alignment**: Human-in-the-Loop (HITL) optimization to safely align model behaviors with real-world human preferences.

---

### Card 7: Agentic Workflows & Tool Integration
*   **Topic**: Autonomous AI Systems
*   **Core Concepts**: Deconstructing advanced "Agentic" systems, task decomposition, and memory management.
*   **Capabilities**: Enabling LLMs to autonomously execute external API calls, web searches, and environment-driven tasks.

---

### Card 8: System Design Building Blocks
*   **Topic**: Scalable Infrastructure Fundamentals
*   **Core Concepts**: Core architecture design principles for high availability and low latency.
*   **Components**: Load balancers, caching layers, reverse proxies, horizontal scaling, and SQL vs. NoSQL datastores.

---

### Card 9: Microservices & Distributed Architecture
*   **Topic**: Decoupled Enterprise Ecosystems
*   **Core Concepts**: Splitting monolithic applications into highly resilient, isolated, and domain-driven services.
*   **Communication**: Event brokers, message queues, RPC/REST communication patterns, and network partition strategies.

---

### Card 10: Security, Estimation & Performance Tuning
*   **Topic**: Production Reliability & Verification
*   **Core Concepts**: Hardening software infrastructure against vulnerabilities while planning for heavy traffic loads.
*   **Tasks**: Data encryption, back-of-the-envelope capacity estimations (QPS, storage), and application bottleneck analysis.

---

### Card 11: Container Engineering & CI/CD Pipelines
*   **Topic**: Modern DevOps Practices
*   **Core Concepts**: Packaging applications securely and automating software shipping cycles.
*   **Key Tools**: Multi-stage Docker containerization, build optimization, and programmatic Continuous Integration / Continuous Deployment (CI/CD) pipelines.

---

### Card 12: Kubernetes Orchestration & GitOps
*   **Topic**: Enterprise Cloud Infrastructure
*   **Core Concepts**: Auto-scaling, self-healing, and managing stateful/stateless workloads across computing clusters.
*   **Methodology**: Cluster orchestration via Kubernetes and declarative, code-driven infrastructure sync using GitOps patterns.

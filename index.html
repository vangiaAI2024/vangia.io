WEEKLY ROADMAP

Embark on an intensive 12-week journey to master artificial intelligence, computer science thinking, and modern systems engineering.

Week 01

Supervised Learning Foundations

Machine Learning Basics
  • Supervised vs. Unsupervised vs. Reinforcement Learning paradigms.
  • SVM, KNN, Logistic Regression, Decision Trees, and Naive Bayes classifiers.
Week 02

Unsupervised Clustering & Vectorization

Data Discovery & Representation
  • Finding patterns in unlabeled data and converting text to numerical formats.
  • Hierarchical Clustering, TF-IDF text features, and advanced Data Visualization techniques.
Week 03

Neural Networks & Validation

Deep Learning Core
  • Forward propagation, loss computation, and backpropagation optimization.
  • Feedforward Networks (FFN), Convolutional Networks (CNN), Recurrent Networks (RNN), and evaluation.
Week 04

Transformers & Ensembling

Modern Sequence Models
  • The "Attention Is All You Need" architecture, self-attention mechanics, and latent spaces.
  • Exploring the Variance of Embeddings and combining models via Ensembling for robustness.
Week 05

LLM Pre-training & Fine-Tuning

Generative AI Customization
  • Downstream adaptation strategies for large foundation models.
  • Implementing Parameter-Efficient Fine-Tuning (PEFT) using memory-optimized LoRA and QLoRA layers.
Week 06

Reinforcement Learning & Alignment

Reward-Based Optimization
  • Training models through trial, error, and feedback loops.
  • Human-in-the-Loop (HITL) optimization to safely align model behaviors with human preferences.
Week 07

Agentic Workflows & Tool Integration

Autonomous AI Systems
  • Deconstructing advanced "Agentic" systems, task decomposition, and memory management.
  • Enabling LLMs to autonomously execute external API calls, web searches, and environment-driven tasks.
Week 08

System Design Building Blocks

Scalable Infrastructure Fundamentals
  • Core architecture design principles for high availability and low latency.
  • Load balancers, caching layers, reverse proxies, horizontal scaling, and SQL vs. NoSQL datastores.
Week 09

Microservices & Distributed Systems

Decoupled Enterprise Ecosystems
  • Splitting monolithic applications into highly resilient, isolated, and domain-driven services.
  • Event brokers, message queues, RPC/REST communication patterns, and network partition strategies.
Week 10

Security, Estimation & Tuning

Production Reliability & Verification
  • Hardening software infrastructure against vulnerabilities while planning for heavy traffic loads.
  • Data encryption, back-of-the-envelope capacity estimations (QPS, storage), and bottleneck analysis.
Week 11

Container Engineering & CI/CD

Modern DevOps Practices
  • Packaging applications securely and automating software shipping cycles.
  • Multi-stage Docker containerization, build optimization, and programmatic Continuous Integration / Continuous Deployment pipelines.
Week 12

Kubernetes Orchestration & GitOps

Enterprise Cloud Infrastructure
  • Auto-scaling, self-healing, and managing stateful/stateless workloads across computing clusters.
  • Cluster orchestration via Kubernetes and declarative, code-driven infrastructure sync using GitOps patterns.
